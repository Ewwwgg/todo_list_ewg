# Todo App — React Native та Expo

Мобільна версія Todo App використовує Expo Router і `json-server` із сусідньої
папки `server`.

## Запуск

У першому терміналі з кореневої папки проєкту:

```bash
cd server
npm start
```

У другому терміналі:

```bash
cd rn-todo-list
npm start
```

У терміналі Expo натисніть `a` для Android Emulator, `i` для iOS Simulator,
`w` для вебверсії або відскануйте QR-код через Expo Go. Для фізичного
пристрою та комп'ютера потрібна одна Wi-Fi мережа; дозвольте вхідні з'єднання
до порту `3000` у брандмауері комп'ютера.

Вебверсія звертається до `http://localhost:3000`. У мобільному застосунку
адреса сервера визначається з адреси Metro (`hostUri`); якщо вона недоступна,
для Android Emulator використовується `http://10.0.2.2:3000`.

## Можливості

- Завантаження та створення завдань.
- Позначення виконаних завдань, редагування й видалення.
- Оновлення списку жестом pull-to-refresh.
- Лічильник виконаних завдань, індикатор завантаження та повторне з'єднання.

Перевірка TypeScript:

```bash
npm run typecheck
```
