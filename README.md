# Todo App 2.0 — React Native та Expo

Мобільний список завдань на React Native з Expo Router, REST API на
`json-server`, трьома вкладками, статистикою та світлою/темною темами.

## Функції

- Керування завданнями: створення, редагування, виконання та видалення.
- Вкладка статистики з кількістю всіх, активних і виконаних завдань та
  відсотком прогресу.
- Налаштування світлої або темної теми зі збереженням вибору в `AsyncStorage`.
- Масове видалення виконаних завдань або очищення всього списку з підтвердженням.
- Спільний стан завдань між вкладками та збереження на REST API.
- Адаптивні кольори таб-навігації, статус-бара й екранів.

## Запуск

З кореневої папки проєкту відкрий два термінали. У першому запусти API:

```bash
cd server
npm ci
npm start
```

У другому, також із кореневої папки, запусти Expo:

```bash
npm ci
npm start
```

У терміналі Expo натисни `w` для вебверсії, `a` для Android Emulator або
відскануй QR-код через Expo Go. Для фізичного пристрою та комп'ютера потрібна
одна Wi-Fi мережа; дозволь вхідні з'єднання до порту `3000` у брандмауері.

Вебверсія звертається до `http://localhost:3000`. У мобільному застосунку
адреса API визначається з адреси Metro (`hostUri`); для Android Emulator є
резервна адреса `http://10.0.2.2:3000`.

## Можливості

- Завантаження, створення, редагування та видалення завдань.
- Позначення завдання виконаним або невиконаним.
- Оновлення списку жестом pull-to-refresh.
- Лічильник завдань, стан завантаження та повторне підключення до API.

Перевірки проєкту:

```bash
npm run lint
npm run typecheck
```
